# Chromium Secure Close

## 概要

Chromium Secure Closeは、Chrome / Braveの閲覧データを削除してから、現在のプロファイルで拡張機能から列挙できる通常・ポップアップウィンドウだけを閉じる、ベータ版のManifest V3拡張機能です。シークレットウィンドウは終了対象から除外します。

「安全」「標準」「完全」の3プリセット、Cookie・キャッシュ・サイトストレージを除外するログイン維持originリスト、popupを開く`Alt+Shift+C`ショートカットを備えます。ログイン維持リストは履歴・ダウンロード履歴・フォームデータを保護しません。

## 動作要件

- Google ChromeまたはBraveのManifest V3対応版
- 拡張機能を読み込むためのデベロッパーモード
- 日常利用とは分離した専用ブラウザープロファイル（推奨）

## インストール

1. Chromeの`chrome://extensions`またはBraveの`brave://extensions`を開きます。
2. 「デベロッパーモード」を有効にします。
3. 「パッケージ化されていない拡張機能を読み込む」から`project/extension/`を選択します。
4. 読み込み後は`project/extension/`を移動・削除しないでください。移動した場合は拡張機能管理画面から読み込み直します。

## 使用方法

1. ツールバーの拡張機能アイコン、または`Alt+Shift+C`でpopupを開きます。ショートカットだけでは削除を開始しません。
2. 削除プリセット、期間、必要に応じてログイン維持リストを確認します。
3. 「削除のみ（閉じない）」または「削除して閉じる」を選び、確認画面で実行します。
4. 中断ジャーナルが表示された場合は自動再削除せず、内容を確認してから「状態を確認済みにする」を押し、再実行します。

## 設定

- 「安全」「標準」「完全（サイトデータ含む）」の3プリセットを選択できます。
- options画面でログイン維持originを登録できます。除外対象はCookie・キャッシュ・サイトストレージだけです。
- ショートカットが競合する場合は、Chromeの`chrome://extensions/shortcuts`またはBraveの`brave://extensions/shortcuts`で変更できます。

## アンインストール

Chrome / Braveの拡張機能管理画面でChromium Secure Closeの「削除」を選択します。アンインストール前に拡張機能が保持する設定を別途消去したい場合は、options画面で内容を確認してください。

## 既知の制限

- 実行すると履歴、キャッシュ、Cookie、ダウンロード履歴、フォームデータを削除できます。ダウンロード済みファイル本体、パスワード、ブックマークは削除しません。
- 削除対象は現在のブラウザープロファイルの通常領域です。`originTypes: { unprotectedWeb: true }` を固定し、hosted appデータと他の拡張機能データは対象にしません。シークレット領域は閲覧データ削除APIの対象外で、シークレットウィンドウも終了しません。
- 別プロファイル、DevTools、バックグラウンドアプリ、ブラウザーのOSプロセス終了は保証しません。シークレットウィンドウから「削除して閉じる」を選ぶ場合は明示的に拒否し、「削除のみ」を選択してください。
- Chrome / Braveのセッション復元設定が有効な場合、次回起動時にタブが復元されることがあります。
- Cookieの維持範囲はregistrable domain全体へ及ぶ場合があり、サブドメイン単位の完全な分離は保証されません。
- 最終ウィンドウを閉じる途中でservice workerが停止する可能性があり、終了結果を完全には観測できない場合があります。
- 現在はベータ版です。日常利用プロファイルでは実行せず、専用の使い捨てプロファイルで受入確認してください。
